# Agent Workspace Contract

`_workspace/`는 여러 세션에 걸친 작업이나 인계에 필요한 기록을 보존하는 임시 공간이다. 작은 작업에는 만들지 않으며 실제 작업 기록은 Git에서 제외된다.

각 작업은 다른 기록을 덮어쓰지 않도록 경로에 안전한 영문·숫자·하이픈으로 된 `_workspace/<작업명>/`을 사용한다. 필요한 파일만 만든다.

- `task.md`: 단일 작업 기록. 양식은 `.agents/skills/npm-package-development/templates/task.md`.
- `00_request.md`: 요청 요약, 완료 조건, 영향 경로, 비목표와 가정.
- `01_plan.md`: API 계약, 변경 파일, 구현 순서와 검증 계획.
- `02_review.md`: `pass | fix | redo`, 조건별 근거, 실행한 명령과 미검증 영역.

원 요청을 임의로 확대하지 않고, 코드 경로와 명령은 저장소 루트 기준으로 쓴다. 확인된 사실과 판단을 구분하며 실패 로그에는 재현에 필요한 핵심만 남긴다. 민감정보는 기록하지 않는다. 완료 시 최종 응답에 변경, 검증 결과와 남은 위험을 요약한다.
