# Agent Workspace Contract

`_workspace/`는 복합 작업의 요구사항, 계획, 리뷰를 세션 사이에 보존하는 임시 공간이다. 작은 수정에는 만들지 않으며, 실제 작업 파일은 Git에서 제외된다.

## 파일 이름

- `00_request.md`: 요청 요약, 완료 조건, 영향 경로, 비목표, 가정
- `01_plan.md`: API 계약, 변경 파일, 구현 순서, 검증 계획
- `02_review.md`: `pass | fix | redo`, 조건별 근거, 실행한 명령, 미검증 영역

## 작성 규칙

- 원 요청을 임의로 확대하지 않는다.
- 코드 경로와 명령은 저장소 루트 기준으로 쓴다.
- 판단과 확인된 사실을 구분한다.
- 실패 로그는 재현에 필요한 핵심만 남기고 비밀값은 기록하지 않는다.
- 작업이 끝나면 최종 응답에 변경 파일, 검증 결과, 남은 위험을 요약한다.
